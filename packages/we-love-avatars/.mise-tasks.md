# Mise Tasks for we-love-avatars

## Development Tasks

### `mise run test`
Run all tests for we-love-avatars package.

```bash
mise run test
```

### `mise run clean`
Clean generated outputs and cache files (examples/output, .pytest_cache, .ruff_cache).

```bash
mise run clean
```

### `mise run clean-all`
Clean everything including the virtual environment.

```bash
mise run clean-all
```

## Example Tasks

### `mise run demo`
Run the demo example and create `output/demo.gif` and `output/demo.png`.

```bash
mise run demo
```

### `mise run examples`
Run all basic examples (creates 5 different animated avatars).

```bash
mise run examples
```

### `mise run open-output`
Create and open the examples output directory in Finder.

```bash
mise run open-output
```

## Quick Workflow

```bash
# Install dependencies
uv sync

# Run tests
mise run test

# Try the seed-based API (recommended!)
mise run seed-based

# Or generate demo
mise run demo

# Or run all examples
mise run examples

# Or enhanced examples
mise run enhanced

# View the output
mise run open-output

# Clean up when done
mise run clean
```
